# 🛍️ Django Shop

Веб-додаток інтернет-магазину, побудований на Django з використанням TailwindCSS для стилізації.

## 📋 Опис

Django Shop - це сучасний веб-додаток для каталогу товарів з можливістю перегляду продуктів за категоріями. Проект включає адміністративну панель для управління товарами та категоріями, а також зручний інтерфейс для користувачів.

## ✨ Основні можливості

- 📦 **Управління товарами** - додавання, редагування та видалення товарів
- 🏷️ **Категорії товарів** - організація продуктів за категоріями
- 🖼️ **Завантаження зображень** - підтримка зображень товарів
- 🔍 **Фільтрація** - перегляд товарів за категоріями
- 📱 **Адаптивний дизайн** - використання TailwindCSS для сучасного UI
- 🔄 **Пов'язані товари** - відображення схожих продуктів
- ⚡ **Автоматичне оновлення** - підтримка django-browser-reload для розробки

## 🛠️ Технології

- **Backend**: Django 5.2.4
- **Frontend**: TailwindCSS
- **База даних**: SQLite3
- **Обробка зображень**: Pillow 11.3.0
- **Python**: 3.x

## 📦 Встановлення

### Передумови

- Python 3.x
- Node.js та npm (для TailwindCSS)

### Кроки встановлення

1. **Клонуйте репозиторій**
```bash
git clone <repository-url>
cd shop
```

2. **Створіть віртуальне середовище**
```bash
python -m venv venv
source venv/bin/activate  # для Linux/Mac
venv\Scripts\activate     # для Windows
```

3. **Встановіть залежності**
```bash
pip install -r requirements.txt
```

4. **Виконайте міграції бази даних**
```bash
python manage.py makemigrations
python manage.py migrate
```

5. **Створіть суперкористувача**
```bash
python manage.py createsuperuser
```

6. **Запустіть TailwindCSS (в окремому терміналі)**
```bash
python manage.py tailwind start
```

7. **Запустіть сервер розробки**
```bash
python manage.py runserver
```

8. **Відкрийте браузер**
```
http://127.0.0.1:8000/
```

```
shop/

├── shop/                    # Налаштування проекту
│   ├── settings.py         # Конфігурація Django
│   ├── urls.py             # Головні URL-маршрути
│   └── wsgi.py             # WSGI конфігурація

├── manage.py               # Django CLI
└── requirements.txt        # Python залежності
```

## 🗄️ Моделі даних

### Category (Категорія)
- `name` - назва категорії
- `slug` - URL-friendly ідентифікатор

### Product (Товар)
- `category` - зв'язок з категорією
- `name` - назва товару
- `slug` - URL-friendly ідентифікатор
- `image` - зображення товару
- `description` - опис товару
- `price` - ціна товару
- `available` - доступність товару
- `created` - дата створення
- `updated` - дата оновлення

## 🔧 Адміністрування

```
http://127.0.0.1:8000/admin/
```

Використовуйте облікові дані суперкористувача для входу.

## 🚀 Розгортання

Перед розгортанням на продакшн:

1. Змініть `DEBUG = False` в `settings.py`
2. Встановіть безпечний `SECRET_KEY`
3. Налаштуйте `ALLOWED_HOSTS`
4. Використовуйте PostgreSQL замість SQLite
5. Налаштуйте статичні файли та медіа
6. Використовуйте gunicorn або uWSGI
